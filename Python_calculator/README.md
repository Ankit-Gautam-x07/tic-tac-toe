# 🧮 Python Expression Calculator

A command-line expression calculator built with Python.

## ✨ Features

- Addition
- Subtraction
- Multiplication
- Division
- Multiple operators in one expression
- Parentheses support
- Decimal numbers
- Division-by-zero handling
- Invalid expression handling
- Clean and modular Python code
- Safe expression evaluation without using `eval()`

## 🛠️ Technologies

- Python
- Standard Python Library

## ▶️ How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Run:

```bash
python calculator.py
